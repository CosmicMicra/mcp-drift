## 1. Server in brief
GIT MCP Server (v1.2.0, TypeScript) provides tools for AI assistants and LLM agents to work with Git repositories: manage repositories, branches, commits, remotes, staging, diffs, and files through a standardised MCP interface. It is for developers who let an agent perform git operations. It runs git against local repository paths given as tool arguments.
