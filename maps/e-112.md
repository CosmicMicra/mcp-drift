## 1. Server in brief
openclaw-mcp is a TypeScript MCP server that bridges MCP clients (Claude.ai web via a custom connector, Claude Desktop) to an OpenClaw AI-assistant gateway, so that "my chat can delegate tasks to my Claw" (an AI assistant orchestrating another). It runs locally or as a Docker image (`ghcr.io/freema/openclaw-mcp`) and talks to the OpenClaw gateway (default `http://127.0.0.1:18789`, `OPENCLAW_URL`) with `OPENCLAW_GATEWAY_TOKEN`. For remote use it has OAuth client credentials (`MCP_CLIENT_ID`/`MCP_CLIENT_SECRET`) and CORS settings. Tools: `openclaw_chat`, `openclaw_status`, `openclaw_chat_async`, `openclaw_task_status`, `openclaw_task_list`, `openclaw_task_cancel`.
