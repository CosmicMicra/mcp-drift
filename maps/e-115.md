## 1. Server in brief
Amazon Seller Central MCP Server is a TypeScript MCP server (early stage, v0.1.0) intended to give AI agents access to Amazon Seller Central data through the Amazon Selling Partner API (SP-API): sales, inventory, returns, listings, reports. It is for Amazon sellers who want an agent to analyse their business, possibly combined with other MCPs (Google Sheets cost data, databases, Notion). It authenticates with AWS credentials plus Login-with-Amazon (LWA) OAuth (client id/secret, refresh token) and seller/marketplace IDs from environment variables (`.env` via dotenv).

## 5. Is `env_secrets` reachable?
**Not from the MCP server in this version.** The secret env reads are in `CredentialsManager.loadFromEnvironment()` (credentials.ts:21-41). The only importers in the repo are `scripts/test-auth.ts` and tests. `src/index.ts` (the MCP server) does not import credentials, token-manager, or sp-api-client, and exposes only the `hello` tool. The code exists in the package source and is presumably intended for future tools.
