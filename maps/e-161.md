## 1. Server in brief
"Blue Team MCP Server (Wazuh SIEM)" is a Python MCP server for Claude Desktop and other MCP clients, described in the README as the defensive counterpart to offensive tooling. It exposes about 123 tools and 4 resources: Wazuh SIEM queries (OpenSearch indexer and Manager API with JWT auth), multi-provider threat intelligence (CrowdSec, ThreatFox, OTX, URLhaus, GreyNoise), MITRE-based "3-Sum" APT correlation, attack graphs, LangGraph investigation workflows, and local host forensics. The README says it is "Read-only by default". Every tool runs through an audit → call → redact → truncate pipeline. It is aimed at SOC / CSIRT analysts.
