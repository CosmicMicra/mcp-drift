## 1. Server in brief
(Same repository as e-61, later range.) Bitbucket MCP is a TypeScript MCP server for the Bitbucket Cloud/Server APIs. AI assistants can list and inspect repositories, manage pull requests (comments, approvals, drafts), and work with Bitbucket Pipelines (list runs, get steps/logs, run, stop). Config comes from env: `BITBUCKET_URL` (default `https://api.bitbucket.org/2.0`), `BITBUCKET_TOKEN`, or `BITBUCKET_USERNAME`/`BITBUCKET_PASSWORD`, with logging controlled by `BITBUCKET_LOG_*`. In this range `dotenv/config` is loaded at startup.
