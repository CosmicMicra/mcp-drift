## 1. Server in brief
cml-mcp is a Python (FastMCP 2.0) MCP server for Cisco Modeling Labs (CML 2.9+), a network simulation platform. With it, an LLM can create lab topologies, query lab, node, and server status, start and stop labs and nodes, manage CML users and groups, and run CLI commands on virtual network devices through PyATS/Genie. It is for network engineers who use AI to build and operate simulated networks. It authenticates to CML with `CML_URL`/`CML_USERNAME`/`CML_PASSWORD` (or per-request `X-Authorization` in HTTP mode). Device logins use `PYATS_USERNAME`/`PYATS_PASSWORD`/`PYATS_AUTH_PASS` (or an `X-PyATS-Authorization` header in HTTP mode).
