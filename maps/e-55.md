## 1. Server in brief
Claw Orchestrator ("A runtime for coding agents", npm `@enderfga/claw-orchestrator`) wraps coding-agent CLIs (Claude Code, Codex, Gemini, Cursor Agent, OpenCode, or custom CLIs) as persistent programmable sessions. It coordinates them in multi-agent "councils" (each agent works in its own git worktree), runs autonomous Planner / Coder / Reviewer loops, and supports "fan-out" (several agents answer the same prompt in parallel, with optional synthesis). Tools are registered through an OpenClaw plugin API (`api.registerTool`) in `src/index.ts`. Users are developers orchestrating several coding agents.
