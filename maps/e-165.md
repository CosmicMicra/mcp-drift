## 1. Server in brief
NOMIK ("The Living Blueprint", "AI-native code intelligence graph") scans a codebase into a persistent Neo4j knowledge graph (functions, classes, files, DB tables, calls, imports) and exposes it to AI assistants via MCP, so the AI queries relationships instead of reading files into the prompt. It ships a CLI (`nomik init`, `nomik scan`, wiki generation), an MCP server (`packages/mcp-server`), a visualiser, a watcher, and, in this range, a GitHub bot. Users are developers using AI coding assistants (Cursor, Windsurf, Claude, …). `nm_search` searches graph nodes by name.
