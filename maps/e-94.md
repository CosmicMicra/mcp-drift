## 1. Server in brief
(Same repository as e-3, later range.) servicenow-api is a Python wrapper for the ServiceNow REST APIs with a FastMCP server (`servicenow_api/servicenow_mcp.py`) that exposes table, incident, change, CMDB, knowledge, and other operations to AI agents. Credentials come from env (`SERVICENOW_INSTANCE`, `SERVICENOW_USERNAME`, `SERVICENOW_PASSWORD`, `SERVICENOW_CLIENT_ID`, `SERVICENOW_CLIENT_SECRET`). In this range an **OIDC token-delegation mode** was added: with `ENABLE_DELEGATION`, the server takes the caller's Bearer token from the incoming MCP HTTP request and exchanges it (RFC 8693 token exchange) at an OIDC token endpoint for a ServiceNow-scoped token.

## 5. Is `network` reachable from this tool?
**Yes.** The named helper `get_client` is the one called: `refresh_auth_token` (:4379) → `get_client(...)` (:4407) → with delegation enabled, `requests.post(config["token_endpoint"], …)`; without delegation, `Api(...)` → password grant POST. Then `client.refresh_auth_token()` → POST to `{instance}/oauth_token.do`.

## 7. Conditions
- Delegation branch: `ENABLE_DELEGATION` true, a Bearer token present in the request, and OIDC config valid (startup exits otherwise).
- `refresh_auth_token()` requires `self.headers`. In delegation mode `auth_data` is not populated (only `token` path), so `self.auth_data["client_id"]` would be undefined (behaviour not executed; see Unknowns).
