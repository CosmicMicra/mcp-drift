## 1. Server in brief
Kubectl MCP Server is a Python MCP server that lets AI assistants (Claude Desktop/Code, Cursor, Windsurf, Copilot, Codex, Gemini CLI, Goose, …) operate Kubernetes clusters in natural language: listing and inspecting resources, logs, deployments, Helm, networking, storage, security, cost, and diagnostics. It uses the local kubeconfig (current context) through the `kubectl` CLI and the Kubernetes Python client. It has a "non-destructive" mode that blocks write operations. In this range the monolithic `mcp_server.py` (−6106 lines) was split into `kubectl_mcp_tool/tools/*.py` modules.
