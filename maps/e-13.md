## 1. Server in brief
IDA Pro MCP Server lets AI assistants drive IDA Pro (disassembler/debugger) for reverse engineering and binary analysis. It has three parts: an IDA Pro plugin (`ida_remote_server.py`) that runs an HTTP server inside IDA (default `127.0.0.1:9045`), a TypeScript client (`idaremoteclient.ts`), and the MCP server (`index.ts`) that exposes tools such as running IDAPython scripts and (new in this range) searching immediate values, strings, text, byte sequences, disassembly, exports, and imports. It is for reverse engineers and security researchers.
