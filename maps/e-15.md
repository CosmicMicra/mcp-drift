## 1. Server in brief
HealthClaw Guardrails (v1.5.0) is described as an open reference implementation of the security and compliance layer between AI agents and clinical (FHIR) data. It provides a Flask FHIR R4/R6 backend with guardrails (tenant isolation, step-up authorization for writes, audit, redaction, consent), health-record connectors (Fasten/TEFCA, HealthEx, Epic, …), and a Node "agent-orchestrator" MCP server (23 MCP tools; `services/agent-orchestrator/src/tools.ts`) that proxies AI tool calls to the backend. Users are developers building health-data AI agents. The demo uses synthetic tenants such as `desktop-demo`.
