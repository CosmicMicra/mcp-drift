## 1. Server in brief
claude-mem-lite is a persistent, cross-session memory plugin for Claude Code. It runs as an MCP server (`server.mjs`, tools such as `mem_search`, `mem_recent`, `mem_save`, `mem_get`, `mem_delete`, `mem_compress`, `mem_optimize`, `mem_export`, `mem_recall`, `mem_defer`, …) plus Claude Code hooks (`hook.mjs`). Together they automatically capture decisions, fixes, and context from coding sessions into a single SQLite database (FTS5 + TF-IDF hybrid search) and re-inject relevant context. The README says "Zero external services". Optional LLM enrichment uses Haiku via `ANTHROPIC_API_KEY`, `OPENROUTER_API_KEY`, or the logged-in `claude` CLI (`haiku-client.mjs`).

## 5. Is `dynamic_code` reachable?
**Only as `import()` of constant in-package module paths.** No `eval`, `new Function`, or `vm` was added. Reachable chain from an MCP tool: `mem_save` → `queueSaveEnrich` → spawn `node hook.mjs enrich-save <id>` → `await import('./lib/save-enrich.mjs')` → `await import('../haiku-client.mjs')`. Module specifiers are string literals. The existing dynamic imports in server.mjs predate this range.
