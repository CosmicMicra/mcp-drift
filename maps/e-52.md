## 1. Server in brief
pentest-ai (`ptai` on PyPI) is offensive security tooling for authorised penetration testing ("Offensive tooling, authorized testing only"). It runs scanning agents against targets and treats each finding as a "candidate" until a named machine oracle re-runs the exploit and reproduces it N/N times, then marks it VERIFIED and emits a replayable "proof capsule". The README says an LLM coordinates the run, but no LLM decides verdicts. It wraps third-party scanners (nuclei, nikto, zap, …) and exposes a CLI plus an MCP server (`mcp_server/server.py`) for AI clients. Users are penetration testers. It connects to the targets under test and stores state in a local SQLite findings DB.
