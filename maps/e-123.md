## 1. Server in brief
YouTube Transcript MCP Server is a small Python (FastMCP) server that retrieves transcripts of YouTube videos for a given URL, using the `youtube-transcript-api` library. It is for users who want an assistant to read or summarise YouTube videos. It optionally routes transcript requests through a Webshare proxy (username/password) or a generic HTTP/HTTPS proxy, configured through CLI options. It provides one tool, `get_transcript`.

## 2. The tool(s)
- `get_transcript` — `src/mcp_youtube_transcript/server.py:~37-67` (`@mcp.tool()`), in both versions.
- Description (docstring, identical): "Retrieves the transcript of a YouTube video."
- Parameters (identical): `url: str` ("The URL of the YouTube video"), `lang: str = "en"` ("The preferred language for the transcript").

## 5. Is `network` reachable?
**Yes.** `get_transcript` → `requests.get("https://www.youtube.com/watch?v=<video_id>")` (server.py:~58). The host is constant (`www.youtube.com`). `video_id` comes from the AI-supplied URL and is interpolated without encoding.
