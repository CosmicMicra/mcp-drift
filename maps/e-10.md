## 1. Server in brief
TestRail MCP Server is an open-source TypeScript MCP server that connects Claude, Cursor, Windsurf, and others to TestRail (test case management). Through it the AI can manage projects, search and create test cases, start test runs, record results, and attach files. It is for QA engineers and AI-assisted test automation. It authenticates to a TestRail instance with `TESTRAIL_INSTANCE_URL`, `TESTRAIL_USERNAME`, `TESTRAIL_API_KEY` (basic auth). The README (new in this range) recommends `output_file` for large datasets "allowing you to run external scripts against the export".
