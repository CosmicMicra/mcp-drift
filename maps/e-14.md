## 1. Server in brief
MCP ECharts generates Apache ECharts charts (line, bar, pie, scatter, sankey, treemap, gauge, …) from AI-provided ECharts options or per-chart-type parameters. It renders server-side to PNG, SVG, or a returned option. It is for users who want charts produced by an AI assistant. It runs locally (stdio). In this range an optional MinIO object-storage upload was added for generated PNGs (configured via `MINIO_*` env vars, loaded also from a `.env` file through dotenv).

## 5. Is `env_secrets` reachable from this tool?
**Yes (new).** `generate_echarts` → `process.env.DEBUG_MCP_ECHARTS` (echarts.ts); → `generateChartImage` → `isMinIOConfigured()` reads `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_ENDPOINT` (minio.ts:13-15) → `getMinIOClient()` uses them as credentials (minio.ts:27-38). The secrets are sent to the configured MinIO endpoint for authentication. They are not returned to the AI (the returned URL contains endpoint, port, bucket, and object name only).
