## 1. Server in brief
windows-computer-use-mcp is a Python (FastMCP) Windows desktop-automation server built on pywinauto ("A tool for agents, and an agent itself"). It exposes ~22 tools (`automation_click`, `automation_screenshot`, `automation_ocr`, …) for MCP clients such as Claude, Cursor, and DeepSeek. It also runs as an autonomous agent (`automation_mission`), a React web dashboard (http://127.0.0.1:10788), and a Tauri desktop app. It is for people automating Windows GUIs (e.g. unattended installer testing). The README points to docs/SAFETY.md before production use. `automation_system` is the "system utility" portmanteau tool: status, help, host info, wait, clipboard, processes, start_app, telemetry.

## 5. Is `env_secrets` reachable from this tool?
**Yes, as a feature-flag env read.** `automation_system(operation="voice_status")` → `os.environ.get("WINDOWS_COMPUTER_USE_MCP_VOICE", "0")` (portmanteau_system.py:229). Only a boolean derived from it is returned. Indirectly, `voice_control` reads `SPEECH_MCP_URL` at import (voice_control.py:18). Neither variable is a credential.
