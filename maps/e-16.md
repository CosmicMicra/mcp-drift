## 1. Server in brief
Raindrop.io MCP Server lets LLMs and AI agents access and manage a user's Raindrop.io bookmarks: collections, bookmarks, highlights, tags, and search. It uses a personal access token (`RAINDROP_ACCESS_TOKEN`). It runs over stdio or HTTP (`MCP_TRANSPORT`) and is published on npm (`@adeze/raindrop-mcp`) and Smithery. It is for Raindrop users who want an assistant to organise or retrieve saved links. Tools are declared in `src/services/raindropmcp.service.ts` (`toolConfigs`).
