## 1. Server in brief
opencode-mcp ("Give any MCP client the power of OpenCode") is an MCP server that bridges Claude, Cursor, Windsurf, VS Code, and others to OpenCode's headless HTTP API, so the AI can delegate coding work (features, debugging, refactoring, tests) to OpenCode sessions. It has ~80 tools, 10 resources, and 6 prompts, with multi-project support and auto-start of the OpenCode server (default `http://127.0.0.1:4096`; config via `OPENCODE_BASE_URL`, optional basic auth `OPENCODE_SERVER_USERNAME`/`OPENCODE_SERVER_PASSWORD`, `OPENCODE_AUTO_SERVE`). In 1.11.0 the server lifecycle moved from spawning `opencode serve` to the in-process `@opencode-ai/sdk` `createOpencodeServer`.
