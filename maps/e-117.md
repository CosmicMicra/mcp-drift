## 1. Server in brief
mcp-memory-libsql is a TypeScript MCP server that provides persistent "memory" for AI assistants as a knowledge graph of entities, observations, and relations stored in libSQL. It supports vector search over embeddings and works with local or remote (Turso) libSQL databases. Tools include `create_entities`, `search_nodes`, `read_graph`, and `create_relations`. It is for users who want an assistant to keep long-term structured memory across sessions. Configuration (database URL, auth token) comes from `src/db/config.ts`.
