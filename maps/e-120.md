## 1. Server in brief
MCPM CLI (npm `@mcpm/cli`) is a command-line tool for managing MCP servers in the Claude desktop app. It adds, removes, enables, disables, and lists servers by editing Claude's configuration file, and it can restart Claude. It can also register itself as an MCP server ("Self-Integration"), exposing the same management functions as tools to Claude: `add-server`, `remove-server`, `enable-server`, `disable-server`, `list-servers`, `restart-claude` (src/mcp.ts). It is for Claude Desktop users managing their MCP configuration.

## 5. Is `env_secrets` reachable?
**Yes, as a read of a standard Windows path variable.** `restart-claude` (mcp.ts:211) → `restartClaude()` → (Windows, Claude not running) `process.env.LOCALAPPDATA` (claude.ts:~316). `LOCALAPPDATA` is a non-secret OS directory variable, used only to build a candidate executable path.
