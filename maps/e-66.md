## 1. Server in brief
actual-budget-mcp (npm `actual-budget-mcp`, Node ≥22) is an MCP server for Actual Budget, a self-hosted envelope-budgeting app. It reads and writes accounts, transactions, categories, budgets, and analyses (trends, splits, transfers, bank sync) through the `@actual-app/api` SDK. It is for Actual users who want an assistant to manage their personal budget. It connects to the user's Actual server using env config: `ACTUAL_SERVER_URL`, `ACTUAL_PASSWORD` or `ACTUAL_SESSION_TOKEN`, `ACTUAL_BUDGET_ID`, optional `ACTUAL_ENCRYPTION_PASSWORD`, `ACTUAL_DATA_DIR`.
