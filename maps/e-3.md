## 1. Server in brief
servicenow-api is a Python wrapper for the ServiceNow REST APIs (application service, change management, CI/CD, CMDB, incidents, knowledge, table API, and others). It also ships an MCP server (`servicenow-mcp`, `servicenow_api/servicenow_api_mcp.py`, FastMCP) "for Agentic AI". It is for ServiceNow administrators and developers who want an AI agent to query and modify ServiceNow records. It connects to a ServiceNow instance URL with basic auth or OAuth password grant (`/oauth_token.do`), configured through env vars or tool arguments (credentials are excluded from the AI-visible schema).

## 5. Is `env_secrets` reachable from this tool?
**Yes, and it already was.** New: `get_table` parameter defaults `os.environ.get("SERVICENOW_PASSWORD")`, etc. (servicenow_api_mcp.py:3871-3896), evaluated when the module is imported. Old: globals `environment_password = os.environ.get("PASSWORD")`, etc. used as the same defaults. Values flow to `Api(...)` and then to the instance in an OAuth POST body or Basic auth header. They are not returned to the AI. These params are in `exclude_args`, so they are not exposed in the tool schema.

## 7. Conditions
- OAuth POST: all four of username, password, client_id, client_secret are non-empty. Otherwise Basic auth if username and password are set. Otherwise `MissingParameterError`.
- `SERVICENOW_INSTANCE` must be set (else `MissingParameterError`, servicenow_api.py:45-46).
- Env defaults are captured at import time (process start), not per call.
