## 1. Server in brief
DaVinci Resolve MCP Server (v2.24.x, npm `davinci-resolve-mcp`) connects AI assistants to Blackmagic DaVinci Resolve (18.5+) through its Python scripting API. It claims 100% API coverage: projects, media pool, timelines, color, Fusion, rendering, and more, with a compact mode (32 tools) and a "full" granular mode (329 tools). It is for video editors and colourists automating Resolve with AI. It connects to a locally running Resolve and auto-launches Resolve if it is not running.
