## 1. Server in brief
build123d-mcp is a Python MCP server that exposes build123d (a Python CAD library on OpenCascade) to AI assistants. The AI runs build123d code in a persistent session (in a worker process with an AST/import sandbox), renders views (PNG via VTK or SVG line drawings), measures geometry, compares shapes, and exports STEP/STL. It closes the loop so the AI "can see the geometry it produces". It is for people designing 3D parts with an AI. Output files may be written only under cwd or the temp directory (`tools/_paths.py`).

## 2. The tool

- Parameters (identical): `direction="iso"`, `objects=""`, `quality="standard"`, `clip_plane=""`, `clip_at=None`, `azimuth=0.0`, `elevation=0.0`, `save_to=""`, `format="png"`.
