## 1. Server in brief
Bitbucket MCP is a TypeScript MCP server for Bitbucket Cloud (and Server) APIs. AI assistants can list and retrieve repositories, manage pull requests, and work with repository content. It is for developers using Bitbucket with an AI assistant. It authenticates with a token from `BITBUCKET_TOKEN` against `BITBUCKET_API_URL` (default `https://api.bitbucket.org/2.0`). (The repository also contains `base.xml`, a Repomix pack of a different Bitbucket MCP codebase. It is not part of this server's code path and is unchanged in this range.)
