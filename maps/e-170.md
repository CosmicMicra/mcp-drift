## 1. Server in brief
mcp-klever-vm is a TypeScript MCP server that provides a knowledge base and developer tooling for Klever VM smart contracts (Klever blockchain, Rust-based contracts). Its tools search documentation, query typed context entries, scaffold projects, and explain the `koperator` CLI (deploy, invoke, upgrade contracts). Storage is in memory or Redis. It is for developers writing and deploying Klever smart contracts with an AI assistant. In this range the knowledge base gained large koperator CLI references (ABI, global flags) and testing guides.
