## 1. Server in brief
bw-modeling-mcp is a TypeScript MCP server that lets AI assistants work directly inside SAP BW/4HANA systems. It reads, creates, and modifies BW modeling objects (InfoObjects, composite providers, DTPs, transformations, queries, planning objects, variables, …) through the same internal SAP ADT/BW modeling REST APIs that Eclipse BWMT uses. The README warns: "Every tool call connects to a live BW system — write operations produce real changes." It can run locally or on SAP BTP Cloud Foundry, with basic auth, cookies, or principal propagation. Users are SAP BW developers and consultants.
