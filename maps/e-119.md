## 1. Server in brief
Gomaa is a Python "local-first hierarchical & neuro-inspired cognitive memory engine for autonomous AI agents" (v4.0.0 "Gomaa Neo"). It stores agent memories (episodic and semantic layers) in SQLite or Postgres with embeddings, a markdown "vault", consolidation and decay, plus a local HTTP dashboard. It exposes an MCP server (`gomaa/mcp_server.py`, protocol 2024-11-05) and a CLI. It is for developers building agents that need persistent memory.
