## 1. Server in brief
AgenticMail is a self-hosted communication platform that gives AI agents real email addresses and phone numbers. It runs a local Stalwart mail server in Docker and integrates Google Voice for SMS and verification codes. It exposes an API server (default `http://127.0.0.1:3829` after this change), an MCP server (`packages/mcp`), an OpenClaw plugin, and, new in this range, a Claude Code integration (`packages/claudecode`) that runs one Claude Code subagent per AgenticMail agent account. Users are people running multi-agent setups in which each agent has its own mailbox. The README contains a section addressed to AI agents with one-line install commands.

## 5. Is `env_secrets` reachable from this tool?
**Yes.** `whoami` → `handleToolCall` → `dispatchToolCall` → `apiRequest` (tools.ts:1911 → 130). Inside, `process.env.AGENTICMAIL_MCP_DEBUG` is read on every call (tools.ts:143). The API keys (from `AGENTICMAIL_API_KEY`, `AGENTICMAIL_MASTER_KEY`, `AGENTICMAIL_ACCOUNT_KEYS_JSON`) are used as Bearer tokens to `API_URL`. The named helper `apiRequest` is the one actually called. Key values are not returned to the AI; with debug on, the first 12 characters go to stderr.

## 7. Conditions
- Per-call identity: `_account` present and resolvable (cache, or MASTER_KEY lookup succeeds). Otherwise default `API_KEY` (soft warning).
- Master lookup network call: `_account` not in cache and `MASTER_KEY` set.
- Debug output: `AGENTICMAIL_MCP_DEBUG` set.
