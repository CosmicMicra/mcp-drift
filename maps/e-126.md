## 1. Server in brief
screener-mcp is a Python MCP server that gives Claude live access to Screener.in (Indian stock fundamentals and screens), NSE, and MCX market data, turning Claude into a research assistant for Indian stocks. Tools cover company pages, screening, market data, technicals, documents, and a local RAG/vector store over filings. Fundamental screening needs a free Screener.in login (credentials via env). Everything else works without API keys. It is published on PyPI.
