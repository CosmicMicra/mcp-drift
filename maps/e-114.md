## 1. Server in brief
ContextGraph ("Stop losing agent context") is a Python memory backend for coding agents and multi-agent teams. It offers governed shared memory with provenance and access control, token-budgeted "context packs", "reactive delta compaction" checkpoints, a branch-aware context cache, and repo-local `.contextgraph/` memory directories. It provides a Python SDK, a CLI, an HTTP API (FastAPI-style `web.py`, default port 8420), and an MCP server (`contextgraph/mcp_server.py`, `contextgraph/mcp_remote.py`) for Claude Code and other agents. This range mainly adds a "World" feature: a browser game-like visualisation of agents in rooms (`contextgraph/world/*`, static JS game), plus a bundled "caveman" Codex plugin.
