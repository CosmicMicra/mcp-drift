## 1. Server in brief
Kiln (PyPI `kiln3d`, AGPL-3.0) is "the open-source MCP server for 3D printing". AI agents (Claude, ChatGPT, Codex, Cursor, Gemini, …) use it to design parts, check printability, slice, queue on real printers (Bambu Lab, Creality, Prusa, Elegoo, Voron, …), monitor cameras, recover from failures, or order external printing and shipping. Every version is kept "Git-style", and the person approves prints. Marketplace tools search, list, and download community models from Thingiverse, MyMiniFactory, and others into local storage. Users are makers and 3D-printing hobbyists or professionals using AI agents.

- `kiln_output_dir()` (new in output_paths.py:80-85) creates the folder with `mode=0o700`. `kiln_temp_dir()` honours a per-request `REQUEST_OUTPUT_ROOT` (for multi-tenant servers).

It added `check_write_location`, `refusal_for_call`, `guard_function`, `install(mcp)`, suffix allow-lists `ARTIFACT_SUFFIXES` / `DOWNLOAD_SUFFIXES`, and a `download_model` entry in a per-tool suffix map (output_paths.py:123 in grep: `"download_model": DOWNLOAD_SUFFIXES - ARTIFACT_SUFFIXES`).
- File writes by this tool (downloading into `dest_dir`) **already existed** in the old version. The new helper adds an explicit `os.makedirs` of the default folder and routes the default through the per-request root.
