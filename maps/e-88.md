## 1. Server in brief
OpenTakeoff is "the measurement engine for building plans" for construction estimating. It measures quantities (floor areas, linear footage, counts) off construction drawings (PDF plan sets). It offers ~53 MCP tools for an AI agent and a browser canvas for a person, sharing one takeoff document. Sheets carry their scale calibration, and measurements carry geometry, method, authorship, and review status. The agent's standard workflow is load plan → set scale → commit shapes under finish-tag conditions → derive bases/transitions → visually check → export a marked-up PDF and report. It runs locally on plan files the user loads.
