## 1. Server in brief
MCP Dev LATAM is a monorepo of ~109 MCP servers (~2,289 tools) covering commerce APIs for Latin America (Brazil, Mexico, Argentina, Colombia, Chile, Peru): payments, banking/Open Finance, fiscal, e-commerce, identity, and "agentic payment protocols". Each package is a separate server (e.g. `@codespar/mcp-pluggy`, `@codespar/mcp-shopee`). It is for developers building AI agents that operate LATAM businesses. In this range new identity servers (bigdatacorp, caf, certta) were added and the Pluggy banking server was extended.
