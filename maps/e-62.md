## 1. Server in brief
BoondManager MCP Server (README in French) is a TypeScript MCP server for the BoondManager API (an ERP/CRM for IT consulting firms). Claude can search, view, create, and modify BoondManager records across 36 domains (158 tools): candidates, resources, contacts, opportunities, timesheets, invoices, internal message threads, and so on. It authenticates via BoondManager JWT components, a pre-built JWT, or basic auth from env vars (stdio), or OAuth2 (HTTP transport). The default API is `https://ui.boondmanager.com/api`. This range added env-configured access policies and optional expiring JWTs.
