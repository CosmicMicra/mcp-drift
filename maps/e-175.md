## 1. Server in brief
genesys-mcp ("Your Genesys Cloud org, in your AI's hands") is an open-source MCP server for Genesys Cloud (contact-centre platform) that runs on Cloudflare Workers with zero dependencies. Its stated purpose is to **build** as well as read: queues, skills, users, wrap-up codes, Architect call flows (with diagrams), and more, from natural-language prompts in Claude or other MCP clients. It calls the Genesys Cloud REST API with the org's OAuth credentials.
