## 1. Server in brief
codex-specialized-subagents is a local stdio MCP server for OpenAI's Codex CLI that delegates work to sub-agents. It runs `codex exec` as a child process with a selected set of "skills". It exposes `delegate_autopilot` (decide whether to delegate and orchestrate one or more runs), `delegate_run` (one specialist sub-agent run), and `delegate_resume` (continue a prior sub-agent thread). Each call writes a run directory under `${CODEX_HOME:-$HOME/.codex}/delegator/runs/<run_id>/` with the prompt, selected skills, event stream, and structured results. Users are Codex CLI users who want parallel, specialised agents. It requires an authenticated `codex` CLI on PATH.

## 5. Is `env_secrets` reachable from this tool?
**Yes, as a config env-var read.** `delegate_run` (server.ts:167) → `buildDelegateCodexConfigOverrides(args, process.env)` (server.ts:272) → `env.CODEX_DELEGATE_REASONING_EFFORT` (configOverrides.ts:39). The value becomes a `-c model_reasoning_effort="<value>"` argument and is recorded in `codex_exec.json`. It is a reasoning-effort setting (README: "set `CODEX_DELEGATE_REASONING_EFFORT` on the MCP server process"), not a credential. Pre-existing env exposure: the entire `process.env` is inherited by the `codex` child (runCodexExec.ts:160), unchanged.

## 7. Conditions
- Env read: always on each call. The default is used only if `reasoning_effort` is empty and no `config_overrides` entry starts with `model_reasoning_effort=`.
- `-c` flags: added for each element of the computed overrides (AI-supplied `config_overrides` passed verbatim).
- Spawn: always (requires `codex` on PATH).
