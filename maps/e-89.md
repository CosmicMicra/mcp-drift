## 1. Server in brief
comfyui-mcp ("drive ComfyUI with ANY LLM") is a local-first MCP server plus a live ComfyUI sidebar agent. It generates images, video, audio, and 3D, authors and runs ComfyUI workflows, manages models and custom nodes, and (in this range) adds training, RunPod, and "Micro-Apps" features. It talks to a ComfyUI server over HTTP and to ComfyUI-Manager for node installs. A separate "panel orchestrator" mode (`comfyui-mcp --panel-orchestrator`) runs background agents (Claude Agent SDK, Gemini, Antigravity `agy`, …) per sidebar tab. It also exposes a token-gated UI bridge (port 9180) through which the panel or a mobile app can call a **whitelist** of tools. Users are ComfyUI users who want AI agents to operate their ComfyUI install.

**No.** `ensureMcpConfig` is a private method of `AntigravityBackend` (orchestrator agent backend). It runs when the orchestrator launches an Antigravity agent. `extract_workflow_dependencies` does not call into the orchestrator. The orchestrator can call this tool (via the whitelist), not the reverse. The tool's own path is: JSON parse → HTTP to ComfyUI/Manager.
