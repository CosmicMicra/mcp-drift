## 1. Server in brief
flow-mcp drives Google Flow (flow.google.com, Google's AI video tool) from Claude, Codex, or other MCP apps, or from a local control panel ("studio"), using Flow's free daily credits rather than the paid video API. It runs on the user's machine, opens its own Chrome profile, signs in as the user, and clicks Flow's buttons through the Chrome DevTools Protocol. There is no extension or hosted service. Users are creators making short videos. Besides Flow automation, it has local post-production helpers using ffmpeg (assemble clips, narration, captions with whisper.cpp). Output goes to `FLOW_MCP_OUTPUT` (default `~/flow-mcp-out`).

## 7. Conditions
- Voice-track writes: `voice_lines` non-empty; every `l.file` exists; ffmpeg installed.
- Film write: always when the tool runs successfully (clips found).
- Output file names: sanitised with `/[^\w.-]+/g → "_"`; directory from `projectDir` (sanitised project name under OUTPUT_ROOT).
- Input files (`clips`, `music`, `voiceover`, `voice_lines[].file`) may be any existing path. They are only read (by ffmpeg).
