## 1. Server in brief
MetaTrader 5 MCP Server is a Python (FastMCP) server that lets AI assistants interact with a locally installed MetaTrader 5 trading terminal (Windows, `MetaTrader5` Python package). It offers market data, account info, positions and history, and order placement (`order_send`, `order_check`). It is for traders building AI trading assistants or agents. In this range `initialize()` and `login()` gained fallbacks to environment variables (`MT5_PATH`, `MT5_LOGIN`/`MT5_USERNAME`, `MT5_PASSWORD`, `MT5_SERVER`), and the server instructions tell the AI not to ask for the password when these are set.

## 5. Is `env_secrets` reachable from this tool?
