## 1. Server in brief
SwarmVault is a local-first "knowledge compiler" for AI agents. It ingests files, URLs, screenshots, PDFs, and code into a vault directory (`raw/`, `wiki/`, `state/`, `agent/`), then compiles them into a markdown wiki, a graph (`state/graph.json`), and a SQLite search index. It offers a CLI (`swarmvault ingest|compile|query|graph …|watch|hook install`), a viewer, and an MCP server (`packages/engine/src/mcp.ts`) for coding agents (Codex, Claude Code, Cursor, etc.). Query and explore results are saved back into `wiki/outputs/` by default. LLM calls go to a pluggable provider (OpenAI, Anthropic, Gemini, Ollama, OpenRouter, …, or a local "heuristic" provider).
