## 1. Server in brief
Markdy is an open-source DSL ("MarkdyScript") for animated architecture and system diagrams that render natively in the browser. The monorepo has a core parser/validator, a DOM renderer with SVG/PNG/GIF export, a CLI, Astro/MDX integrations, a language server, and an MCP server (`packages/mcp-server`). The MCP server offers tools to validate Markdy code, transpile Mermaid, Docker Compose, Kubernetes manifests, Terraform state, or draw.io into Markdy, explain an architecture, and generate prompts. It is for developers documenting system architecture with AI help.
