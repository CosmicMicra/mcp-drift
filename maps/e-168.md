## 1. Server in brief
d365fo-client is a Python client library, CLI, and "production-ready" MCP server that exposes Microsoft Dynamics 365 Finance & Operations (D365 F&O) to AI assistants. It covers OData entity CRUD, metadata browsing, labels, actions, and environment "profiles" that store connection settings (base URL, auth/credential source, cache options). It is for D365 F&O developers and consultants. It authenticates against Azure AD (default Azure credentials, client credentials, or credentials taken from environment variables or Azure Key Vault). In this range the default `d365fo-mcp-server` entry point moved from the legacy `mcp.main` server to a FastMCP-based server (`mcp.fastmcp_main`).
