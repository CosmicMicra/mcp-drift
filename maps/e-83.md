## 1. Server in brief
Architect MCP Server ("The AI agent workshop that builds its own tools") lets an AI agent write, test, and save its own JavaScript tools at runtime. Once the user approves them, they run in a restricted sandbox, with network, filesystem, or environment access granted through "capability scopes". It also has a web dashboard (port 3001), cron scheduling and pipelines, webhooks, a global marketplace (browse, install, and publish tools using a GitHub token), and persistent SQLite storage. Users are developers who want agents to extend their own toolset. `list_permissions` shows which capability sets the user has approved for each custom tool.
