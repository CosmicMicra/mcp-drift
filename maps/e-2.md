## 1. Server in brief
ebay-mcp is a TypeScript MCP server (npm `ebay-mcp`) that gives AI assistants access to eBay's Sell APIs: 322 tools covering inventory, order fulfillment, marketing, analytics, developer tools, and more ("API Coverage: 100% (270 unique eBay API endpoints)"). It is for eBay sellers and developers who want to manage listings and orders from Claude, Cursor, Cline, and similar clients. The README says it "Runs locally — no cloud relay". It authenticates to eBay's production or sandbox REST APIs with OAuth client credentials (`EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET`, `EBAY_REDIRECT_URI`) and user tokens (`EBAY_USER_REFRESH_TOKEN`, stored in `.env`).
