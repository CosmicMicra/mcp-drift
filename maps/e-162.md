## 1. Server in brief
fastmail-mcp is a TypeScript MCP server that gives AI assistants access to a Fastmail account through the JMAP API (email, contacts, identities) and CalDAV (calendars). Features: list, search, read, send, reply to, and draft emails; mark, move, label, and delete messages; download attachments; bulk operations; contacts lookup; calendar listing and event creation. It is for Fastmail users who want an assistant to work with their mailbox. It authenticates with a Fastmail API token, plus optional CalDAV app-password credentials (`FASTMAIL_CALDAV_USERNAME` / `FASTMAIL_CALDAV_PASSWORD`).
