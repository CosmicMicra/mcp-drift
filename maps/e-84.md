## 1. Server in brief
IMAP MCP Server is a TypeScript MCP server that gives AI assistants IMAP email access (search, read, move, mark, delete, bulk delete), SMTP sending (send, reply, forward), folder management, and multiple accounts with connection pooling. Account credentials are stored encrypted (AES-256, per the README) in `~/.imap-mcp/accounts.json`, configured through a web-based setup wizard with presets for 15+ providers (Gmail, Outlook, Yahoo, …). Spam tools check message senders against known spam/disposable domains. Users are people who want an assistant to triage and manage their mailboxes.
