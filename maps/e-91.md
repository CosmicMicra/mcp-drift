## 1. Server in brief
BoondManager MCP Server (README in French) is a TypeScript MCP server for the BoondManager API (a French ERP/CRM for IT services and consulting firms). Claude (Desktop, Cowork, Code) can search, view, create, and modify records: candidates, resources, contacts, companies, opportunities, timesheets, projects, invoices, orders, absences, expenses, webhooks, and so on (158 tools across 36 domains). It authenticates via BoondManager JWT components, a pre-built JWT, basic auth (stdio), or OAuth2 (HTTP transport), against `https://ui.boondmanager.com/api` by default. In this range it gained an access policy (env-configured domain/operation allow-lists) and optional expiring JWTs.
