## 1. Server in brief
Mi Fitness Data Bridge (README in Chinese, with an English version in README.en.md) saves a user's Xiaomi Mi Fitness health data (activity, sleep, workouts, body measurements) to their own computer and exports it as CSV, JSON, or SQLite. It is for personal backup and analysis. It also offers a Python API and a local stdio MCP server for querying the cached data. It is "unofficial, experimental" and relies on non-public Xiaomi cloud interfaces. Credentials are configured only through a local interactive CLI and stored in the OS keyring. A static demo with synthetic data needs no login.
