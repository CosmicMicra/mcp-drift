## 1. Server in brief
Misata ("You declare the outcome. Misata generates the data that provably matches it.") is a Python synthetic-data generator. It produces realistic relational datasets that hit stated targets (revenue curves, fraud rates, referential integrity, statistical structure) from a sentence, YAML, or an existing database schema, without real data or an ML model. It has a CLI, an optional LLM-based story parser, and an MCP server (`misata/mcp/server.py`) with tools such as `list_domains`, `preview_story`, `inspect_schema`, `generate_dataset`, `generate_from_schema`, and `validate_yaml`. It is for data engineers and developers who need test or demo data. This range adds curated "domain capsules" (vocabulary JSON for 24 domains) and Wikidata-based vocabulary discovery.
