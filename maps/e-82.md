## 1. Server in brief
Summer Engine ("The game engine built for AI") ships an MCP server, a `summer` CLI, and game-dev skills in one npm package (`summer-engine`). Agents (Claude Code, Codex, Cursor, VS Code, …) use it to build, test, and publish multiplayer games. Two MCP servers are offered: a hosted cloud server (`https://mcp.summerengine.com/mcp`) for assets, search, and publishing, and a local server (`summer mcp`) that drives the Summer Engine desktop app on the user's machine. "Summer Apps" are team tools inside Summer Studio. The `summer_app_*` tools create, publish, and observe them through Summer's cloud gateway (default `https://www.summerengine.com`) using a signed-in token.
