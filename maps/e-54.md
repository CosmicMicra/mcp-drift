## 1. Server in brief
Apra Fleet is an open-source MCP server that pairs AI coding agents (Claude Code, Gemini, Codex, Copilot CLIs) into "doer-reviewer loops" and orchestrates them across machines over SSH. You register local or remote "members" (machines with an AI provider CLI), send and receive files, run prompts and shell commands on members, provision LLM and VCS credentials (GitHub App tokens, Bitbucket, Azure DevOps), and set up SSH keys. It stores its registry and state under `APRA_FLEET_DATA_DIR` (default `~/.apra-fleet/data`). It is for developers coordinating multiple coding agents and machines from one conversation.
