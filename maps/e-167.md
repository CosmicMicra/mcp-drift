## 1. Server in brief
mcp-server-atlassian-bitbucket is a TypeScript MCP server (and CLI) that connects AI assistants to Atlassian Bitbucket Cloud. It lists and inspects workspaces, repositories, branches, commit history, and pull requests (including comments and diffs), and searches code and content. It is for developers who want an assistant to review or navigate Bitbucket repositories. It authenticates with Bitbucket credentials (app password or Atlassian API token) configured through env vars or a config file.
