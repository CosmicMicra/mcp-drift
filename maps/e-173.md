## 1. Server in brief
Node9 ("What did your AI agent actually do? Find out.") is a security layer that sits between AI agents (Claude Code, Codex CLI, Gemini CLI, Cursor, Windsurf, Claude Desktop, …) and their tools. It **discovers** past agent activity (credential leaks, loops, blocked operations, reachable secrets), **protects** in real time by reviewing or blocking risky commands (`rm -rf`, `git push --force`, credential reads, `curl | bash`, …) with human approval channels, and **reviews** activity over time windows. It ships a CLI, a daemon, a TUI dashboard, "shields" (rule packs), and an MCP server (`src/mcp-server/index.ts`) that exposes status, config, shields, rules, undo, egress controls, and approver settings to the agent. Config lives in `~/.node9/config.json`.
