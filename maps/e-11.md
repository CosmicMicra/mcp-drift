## 1. Server in brief
Zotero MCP ("Chat with your Research Library — Local or Web") is a Python MCP server that connects Claude, ChatGPT, and other clients to a Zotero reference library. It searches items, reads metadata, full text and PDFs, gets annotations and notes, runs semantic search, and writes items and notes. It works against the local Zotero desktop app (local API / Better BibTeX, `ZOTERO_LOCAL=true`) or the Zotero web API (API key). It is for researchers managing literature with an AI assistant. In this range a new `zotero_mcp/library.py` adds a read backend that reads `zotero.sqlite` directly so that reads work even with Zotero closed.
