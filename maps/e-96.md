## 1. Server in brief
reddit-mcp-server is a TypeScript MCP server for Reddit: browse subreddits, search, read posts and comments, look up users, and (with user credentials) post, comment, and manage your own content. It supports anonymous, auto, and authenticated modes (OAuth app credentials `REDDIT_CLIENT_ID`/`REDDIT_CLIENT_SECRET`, optional `REDDIT_USERNAME`/`REDDIT_PASSWORD`). In this range, Reddit's blocking of the unauthenticated JSON API led to an **RSS fallback** (`src/client/rss-client.ts`) for anonymous mode. Most per-user tools (including `get_user_posts`) now require OAuth.

## 4. What changed for this tool
- `getUserPosts`: added `if (this.usesRss) return this.requiresOAuthError("get_user_posts")` at the start. The rest is unchanged.
- `RedditClient` constructor: `this.usesRss = this.authMode === "anonymous" || (this.authMode === "auto" && !this.hasCredentials)`; new `RssClient`.
- `makeRequest`: removed the HTML-403 `NetworkBlockedError` detection.
- `authenticate()`: not changed in this range (its token POST existed before).
- Description: "works anonymously" → "requires OAuth credentials".

## 5. Is `network` reachable from this tool?
**Yes, when OAuth credentials are configured, and it already was.** `get_user_posts` → `getUserPosts` → `makeRequest` → (token needed) `authenticate()` → POST to `https://www.reddit.com/api/v1/access_token`, then GET `/user/<name>/submitted.json`. New: in anonymous mode the tool now returns an error **without** any network request (it used to call the unauthenticated JSON API).
