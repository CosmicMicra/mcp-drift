## 1. Server in brief
google_workspace_mcp is a Python (FastMCP) MCP server that gives AI assistants natural-language control over Google Calendar, Drive, Gmail, Docs, Sheets, Slides, Forms, Tasks, and Chat. It works with free Google accounts and Workspace plans, offers remote OAuth 2.1 multi-user support, and has a one-click Claude installation (`.dxt`). It authenticates users via Google OAuth (client secrets from config/env) and stores per-user credentials. In this range it gained a large set of Google Docs editing tools (tables, headers/footers, batch operations). `start_google_auth` starts the OAuth flow for a given user email and service.
