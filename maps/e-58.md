## 1. Server in brief
(Same repository as e-86; this is a later range.) opencode-mcp is an MCP server that bridges AI clients (Claude, Cursor, Windsurf, VS Code, …) to OpenCode's headless HTTP API, so the AI can delegate coding tasks to OpenCode sessions. It manages sessions, messages, files, config, providers, and so on (~80 tools). In this range it moved to MCP SDK v2 (`@modelcontextprotocol/server`), added a durable job system (`src/jobs.ts`, `JobService`) for long-running tasks (`opencode_run`/`fire`/`check`/`job_*`), task transport, and input-required flows. It connects to an OpenCode server (default `http://127.0.0.1:4096`, optional basic auth).
