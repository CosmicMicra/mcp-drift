Check whether each change the tool detected really happened, and whether it matters. Your answers save automatically.

What is labelling, and how do I do it? (read once, 3 minutes)

Our program scanned thousands of MCP servers and flagged moments where a tool seemed to gain a new power (running shell commands, reading secrets, writing files) without the description users approved changing. The program is automatic and makes mistakes. Labelling means you check a random sample by eye and record whether each flag is right. Those answers become the accuracy numbers in the paper.

  1. Read the card: it says which tool, which power, and between which two versions.
  2. Click Open the code change on GitHub. It shows the diff: green lines were added, red removed.
  3. Press Ctrl+F (Cmd+F on Mac) and search for the words in "What to look for", or the tool name.
  4. Choose one label. Add a note if anything is odd. The page moves to the next item.
  • Extraction error: the program was wrong. The power was not actually added to this tool (code just moved, a rename, the wrong function matched, the search terms appear only in tests or comments).
  • Real but benign: the power really was added, but it is ordinary (reading a config setting like a port or log level from the environment, writing a cache or log file).
  • Security relevant: really added, and someone who approved the old version would reasonably want to know (runs commands built from user input, reads tokens or keys, writes or deletes user files, sends data to a new server).
  • Unsure: you cannot tell in about 3 minutes. That is fine; skip ahead.
Worked example (item 1, already checked by Claude): kopfrechner/gitlab-mr-mcp, tool get_projects, flagged for reading environment variables. In the diff, searching process.env finds two new lines reading MR_MCP_MIN_ACCESS_LEVEL and MR_MCP_PROJECT_SEARCH_TERM, which filter the project list; the README documents them. Real, but ordinary configuration → Real but benign.

Keyboard: 1–4 choose a label, ←/→ move. Do the first 20 of each tab, then tell Claude so we can compare answers before you do the rest. Spend at most 3 minutes per item.
